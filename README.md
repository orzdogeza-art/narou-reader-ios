# なろう読み上げ (iPhone アプリ)

小説家になろうの小説を、iPhone で読み上げるアプリです(SwiftUI)。

## 機能
- 作品名の検索 / Nコード・URL から開く
- ランキング(日間・週間・月間・四半期・年間・累計、ジャンル・種別で絞り込み)
- お気に入り(更新があるとバッジ表示)、既読・読んだ位置の保存、「続きから / 最初から」
- 読み上げ: 1話ぶんを最初から全部まとめて iPhone の読み上げに渡すので、画面を消しても続く
  (ロック画面からの再生・停止・前後の話にも対応)
- 速度・声・文字の大きさ・行間・画面の色の設定

## ビルドの仕組み
GitHub Actions(クラウドの Mac)で、署名なしの IPA を作ります。
`Actions` タブ → 最新の実行 → `NarouReader-ipa` をダウンロードします。

## iPhone への入れ方(Mac なし・無料)
Windows パソコンの Sideloadly で、無料の Apple ID を使って署名して入れます(7日ごとに入れ直し)。
